# Arul Shakthi C — Portfolio

A responsive single-page React portfolio built with Vite, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown in the terminal.

## Personalise before publishing
- Replace `public/images/profile.jpg` with your own portrait (keep the same filename).
- Add your resume as `public/Arul-Resume.pdf`.
- In `src/App.jsx`, replace `YOUR_EMAIL@example.com` and `YOUR_GITHUB_USERNAME`.
- Review project descriptions, skills, internship details and learning entries. Remove anything that does not accurately describe your work.
- Add verified certificate images to `public/certificates/` and update the Learning section if desired.

## Build
```bash
npm run build
npm run preview
```

## Publish with GitHub + Vercel
1. Create a public GitHub repository and push this project.
2. Sign in to Vercel with GitHub and import the repository.
3. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
4. Deploy. Vercel can redeploy automatically after future pushes to the connected GitHub repository.

This is a starter portfolio. Confirm all personal details and replace placeholders before making it public.
